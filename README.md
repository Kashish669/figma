# EcoNest — Sustainable Living Companion

Responsive landing-page UI/UX concept for people who want to save energy, build eco-friendly habits, and earn green rewards.

## Screens
Desktop (1440px), tablet (768px), mobile (390px).

## Deliverables
Editable SVG designs, responsive interactive `index.html` demo, design system guide.
