# 🌿 EcoNest – Smart Sustainable Living Platform

## 📌 Project Overview
EcoNest is a modern, responsive, and interactive UI/UX landing page designed to promote sustainable living. The platform helps users develop eco-friendly habits, monitor energy consumption, and explore green rewards.

The project focuses on creating an attractive, user-friendly, and responsive interface using Figma and modern web technologies.

## 🎯 Target Audience
- Environment-conscious individuals
- Students and young professionals
- People interested in sustainable living
- Users looking to reduce energy consumption
- Eco-friendly lifestyle enthusiasts

## ✨ Key Features
- Modern and attractive landing page
- Fully responsive desktop, tablet, and mobile designs
- Interactive navigation and buttons
- Energy consumption insights
- Eco-friendly habit tracking
- Green rewards and achievements
- Reusable UI components
- Consistent typography, colors, and spacing
